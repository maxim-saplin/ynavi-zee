# Disable Ads And Promo Banners

Two build-time flags control the banner surfaces patched in this repo:

- `ZEEAPP_ENABLE_AD_BANNERS`
- `ZEEAPP_ENABLE_PROMO_BANNERS`

Both flags accept `1` or `0`.

## Scope

`ZEEAPP_ENABLE_AD_BANNERS=0` disables these ad surfaces:

- Yandex ad card banner layout
- monetization feed banner container
- guidance banner ad container
- SDK banner container layout
- ad runtime manifest entries used by the Yandex mobile ads SDK

`ZEEAPP_ENABLE_PROMO_BANNERS=0` disables these promo surfaces:

- search and placecard promo banner layout
- tanker promo banner container
- bank promo banner list items and internal promo banner views

## Out Of Scope

These flags do not change unrelated non-ad banner UI, including paywalls,
permission prompts, quota banners, or other informational banners.

## Recommended Defaults

The preset build scripts in the repo now set both flags to `0` so packaged
builds ship without ad or promo banners by default.

To re-enable a banner family for testing, set the corresponding flag back to
`1` in `features/config.env` or in a preset build script.
