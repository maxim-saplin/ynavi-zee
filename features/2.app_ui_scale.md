# App-wide UI scale (density-based)

## What it does

Adds **configurable app-wide UI scaling** that scales **all UI elements together** (including text, layouts, and drawables) using a density-based approach.

- The scaling is applied by overriding the `Configuration.densityDpi` used by the app's `Context`
- This ensures consistent scaling across all UI elements since Android's sizing is largely derived from **dp/sp → px** conversions based on density
- The scale factor is read from a resource file and can be easily adjusted

## How to change the scale factor

Edit the scale factor in:

- `src/res/values/zeeapp_scaling.xml`

Resource:

- `zeeapp_ui_scale` (fraction, percentage)

Examples:

- Disable scaling (baseline): `100%`
- 1.5x scaling (everything 1.5x larger): `150%`
- 0.75x scaling (everything 0.75x smaller): `75%`

## Code changes (where and what)

### Scale resource

File:

- `src/res/values/zeeapp_scaling.xml`

Content:

- Defines `<fraction name="zeeapp_ui_scale">100%</fraction>` (default: 100% = no scaling)

### Helper class

File:

- `src/smali_classes2/ru/yandex/yandexnavi/zee/ZeeUiScale.smali`

Methods:

- `wrapBaseContext(Context): Context` - Wraps a context with scaled density configuration
- `applyToConfiguration(Context, Configuration): Configuration` - Applies scaling to a Configuration object (used for override configurations)

### AppCompat base (Activities)

File:

- `src/smali/androidx/appcompat/app/s.smali`

Change summary:

- In `attachBaseContext(Context)`, after AppCompat's delegate wraps the context, apply scaling:
  - `p1 = ZeeUiScale.wrapBaseContext(p1)`
- This covers the bulk of UI screens that inherit from AppCompat

### Application base context

File:

- `src/smali_classes2/ru/yandex/yandexmaps/app/p2.smali`

Change summary:

- In `attachBaseContext(Context)`, after existing language logic finalizes `p1`, apply scaling:
  - `p1 = ZeeUiScale.wrapBaseContext(p1)`
- This ensures app-level resource access during startup sees the scaled density

### MapActivity locale override

File:

- `src/smali_classes2/ru/yandex/yandexmaps/app/MapActivity.smali`

Change summary:

- In `attachBaseContext(Context)`, right before `applyOverrideConfiguration(languageConfig)`, adjust the config:
  - `languageConfig = ZeeUiScale.applyToConfiguration(this, languageConfig)`
- Reason: this activity applies a locale override via `applyOverrideConfiguration(...)`; without this, the override config may carry the **unscaled** `densityDpi` and revert scaling
