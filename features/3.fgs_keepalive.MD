# Foreground-service keepalive (Android 11 head units)

## What it does

Starts an **always-on foreground service** at app launch to keep the app process alive on devices with aggressive background killing.

- Service: `ru.yandex.yandexnavi.keepalive.KeepAliveService`
- Type: `android:foregroundServiceType="dataSync"`
- Behavior: posts an **ongoing** notification and returns `START_STICKY`

## How to configure (build-time)

This feature is controlled via `features/config.env`:

- `ZEEAPP_KEEPALIVE_ENABLED=1` — enabled (service declared + started)
- `ZEEAPP_KEEPALIVE_ENABLED=0` — disabled (service not declared/started)

Note: Android 8+ requires a notification for foreground services; “keepalive without notification” isn’t supported.

## Where it’s wired

- Manifest service declaration (toggled as a marked block):
  - `src/AndroidManifest.xml`
- Launch hook (toggled as a marked block):
  - `src/smali_classes14/ru/yandex/yandexmaps/launch/LaunchActivity.smali`
- Service implementation:
  - `src/smali_classes2/ru/yandex/yandexnavi/keepalive/KeepAliveService.smali`

## How to verify (ADB)

- Confirm service exists:

```bash
adb shell dumpsys activity services | grep -n "ru.yandex.yandexnavi/.keepalive.KeepAliveService"
```

- Confirm notification/channel:

```bash
adb shell dumpsys notification --noredact | grep -n "channel=keepalive"
```
