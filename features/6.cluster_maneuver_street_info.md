# 6 — Cluster maneuver street info (map-pixel chrome)

## Why
Zee Power Toys HUD minimap must show street / approach chrome from **YNavi's
own** `NaviGuidanceLayer` (GPU map pixels), not a Flutter ETA plate.

`isManeuverStreetInfoVisible()` was gated by a projected-session experiment
(`integrations/projected/i0.B()`), often **false** on car → no street label on
the cluster TextureView. Power-toys 0055 briefly painted a Flutter stand-in;
Maxim redirected: delete the plate, force this native toggle on.

## Patch
- `platformkit/di/projectedsession/b1.smali` — `isManeuverStreetInfoVisible()` always `true`
- `bk1/s.smali` — `setManeuverStreetInfoVisible(true)` at layer create (belt)

## Rebuild / install
```bash
cd ynavi-zee && ./build_zeekr.sh
adb install -g -r -d builds/zeekr_signed.apk
```

Power-toys tip still needs `adb install -r` after removing `MinimapGuidanceOverlay`.
