# MapActivity letterbox padding (top/bottom bands)

## What it does

Adds **configurable empty bands** at the **top and bottom** of the main launcher screen (Map/Navi activity), shrinking the usable map UI vertically.

- The bands are filled using `@color/bg_surface` (has `values/` and `values-night/` variants).
- Runtime theme toggles are supported by repainting the wrapper background from `MapActivity.onConfigurationChanged(...)` when `uiMode` changes.
- The main content is still hosted under the same root view id (`@id/map_activity_root`), so existing insets/lookup logic keeps working.

## How to change the padding sizes

Edit these constants in:

- `src/res/values/dimens.xml`

Dimens:

- `zeeapp_letterbox_top` (top band height, in `dip`)
- `zeeapp_letterbox_bottom` (bottom band height, in `dip`)

Examples:

- Disable letterboxing: set both to `0.0dip`
- Default letterboxing: set both to `105.0dip`

## Code changes (where and what)

### Layout change (MapActivity root wrapper)

File:

- `src/res/layout/maps_activity.xml`

Change summary:

- Replaced the anonymous outer root `<FrameLayout>` with a vertical `<LinearLayout>` that:
  - Sets `android:background="@color/bg_surface"`
  - Adds a top spacer `<View>` with height `@dimen/zeeapp_letterbox_top`
  - Makes the existing `@id/map_activity_root` the weighted middle child (`layout_height="0.0dip"`, `layout_weight="1"`)
  - Adds a bottom spacer `<View>` with height `@dimen/zeeapp_letterbox_bottom`
- All existing children under `@id/map_activity_root` remain unchanged.

### Runtime theme changes (day/night while app is running)

Files:

- `src/AndroidManifest.xml`
- `src/smali_classes2/ru/yandex/yandexmaps/app/MapActivity.smali`

Change summary:

- `MapActivity` handles `uiMode` in `android:configChanges` so it receives `onConfigurationChanged(...)` callbacks.
- `MapActivity.onConfigurationChanged(...)` repaints the letterbox wrapper background by resolving `@color/bg_surface` from a `createConfigurationContext(newConfig)` and applying it to the wrapper view (the parent of `@id/map_activity_root`).

### Dimen constants

File:

- `src/res/values/dimens.xml`

Added:

- `<dimen name="zeeapp_letterbox_top">…</dimen>`
- `<dimen name="zeeapp_letterbox_bottom">…</dimen>`
